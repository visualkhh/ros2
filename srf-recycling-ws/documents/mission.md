## 미션 (팀 원문)

**미션 한 문장**
로봇이 작업 영역 내 캔, 페트병, 종이 등의 재활용품을 인식하고 집어서 종류별 분리수거함으로 옮긴다.

**시작 상태**
로봇은 지정된 초기 자세에서 시작하며, 재활용품은 작업 영역 내 임의의 위치와 방향으로 배치한다. 분리수거함은 지정된 위치에 배치한다.

**물품 선택 기준**
카메라 영상과 언어 명령을 기반으로 물품의 종류를 판단한다. 후보가 여러 개라면 접근 및 집기가 가능한 물품부터 처리한다. 분류가 불확실하거나 대상 물품이 없으면 행동을 보류한다.

**모델 담당 동작**
VLA는 물품 인식, 분류, 접근, 집기, 이동, 놓기 동작을 담당한다. 로봇의 관절 가동 범위, 충돌 방지, 속도 및 작업 영역 제한을 준수한다.

**결과 판정**
물품이 올바른 분리수거함 내부에 들어가고 그리퍼에서 완전히 분리되면 성공으로 판단한다. 잘못된 분류, 물품 낙하, 집기 실패는 실패로 기록한다. 카메라로 결과를 확인할 수 없으면 미확인으로 분류한다. 목표 위치와 실제 위치의 차이는 카메라 좌표를 로봇 기준 좌표로 변환하여 측정한다.

**재시도·사람 개입**
인식 또는 집기 실패 시 현재 상태를 다시 관측하고 최대 2회 자동 재시도한다. 반복 실패하거나 충돌 위험이 발생하면 정지한다. 사람 개입 시 실패 원인, 물품 종류, 로봇 상태, 재시도 횟수를 기록한다.

## 발제 요구사항 대비 점검 (팀 검토 필요)

| 발제 요구 | 현재 미션 | 채울 것 |
|---|---|---|
| **VLM**으로 대상 선택 (정상·모호·부재 단위 시험) | "카메라 영상과 언어 명령으로 종류 판단"만 있고 VLM/VLA 역할 구분이 없음. 원문은 인식·분류도 VLA에 둠 | 대상 선택·보류는 **VLM**, 접근~놓기는 **VLA**로 나누는 것이 발제와 맞음 |
| 3D 위치 + 로봇 기준 좌표 | 결과 판정에만 좌표 변환이 있음 | 물품 선택 직후 3D 위치 단계를 공정에 명시 |
| SLAM 지도 + Nav 이동 + **장애물 정지·우회·재개** | 없음 | 작업 영역 ↔ 수거함 구간을 Nav로 이동, 장애물 시험 구간 지정 |
| 성공을 **mm**로 판정 | "내부에 들어가면" (정성) | 수거함 내곽 기준 거리·허용 오차 수치 |
| VLA 허용 범위 (좌표계·단위·범위 검사, 범위 밖 거부) | 제한 항목 나열 | 어댑터 검사 규칙(관절 한계 값, 속도 상한, 작업 영역 상자 좌표)과 거부 기록 형식 |
| 물품 1개 전체 공정 먼저 | 여러 종류·여러 개 | v1 최소 공정: **물품 1개(예: 캔) → 해당 수거함** 부터 |

## 시뮬레이션 환경 — [README](../README.md#시뮬레이터)

- 실물 시험 전 연습·단위 시험용. **시뮬레이션 성공은 실물 성공으로 합산하지 않는다** (발제 ⑨).
- 작업 영역 안에 캔·페트병·종이를 **임의 위치·방향**으로 배치 (시드 고정 가능 → 회차 재현), 분리수거함은 지정 위치.
- 정상·모호·부재 장면을 설정으로 만들 수 있어야 한다.
- 판정(성공·실패·미확인)과 배치 오차를 시뮬레이터 진실값(`recycling/truth`)으로도 계산해, 카메라 기반 판정과 비교할 수 있게 한다.
- 구현됨: 재활용 선별장(구역·설비·걷는 작업자·지게차·컨베이어), 물품 카탈로그(캔·페트·종이·불확실·비대상 변형), 장면 `normal`·`multi`·`ambiguous`·`absent`, 시드 재현, 3D 카메라(텍스처·투명·그림자), 진실 판정(바구니·낙하), 재배치 서비스.
