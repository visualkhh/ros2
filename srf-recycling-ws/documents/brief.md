# 프로젝트 3 발제 정리 — 물류/공정 자동화 시나리오 구현

> 출처: 팀스파르타 노션 「프로젝트(3) 발제」 (팀 권한 페이지). 2026-11-28에 읽고 정리했다.
> 원문이 바뀌면 원문이 우선이다. 이 문서는 팀이 빨리 찾아보려는 요약이며, 일부 표현은 원문 그대로 옮겼다.

## 한눈에

- **만드는 것**: 카메라 영상과 지시로 물품을 고르고, 위치 확인 → 이동 → 집기·놓기 → 배치 확인까지 **이어지는** 실물 로봇 시스템. 기능을 따로 보여주는 게 아니라 앞 단계 결과가 다음 동작으로 이어져야 한다.
- **모든 팀 공통**: 단일 로봇으로 수행 가능한 물류 미션에서 **VLM으로 작업 대상을 판단**하고, **VLA가 생성한 행동을 공정 한 단계 이상**에 적용해 검증한다.
- **일정**: 12/2 ~ 12/14, 9일(하루 8시간). 9일차 최종 시연.
- **제출**: GitHub main 브랜치에 최종 코드 병합 (기존 저장소면 `project3/`), 프로젝트명 + GitHub 링크 + 팀 노션 링크. 평가자가 영상·로그·bag을 열 수 있어야 한다.
- **보안**: 비밀번호·API 키·접속 토큰·불필요한 개인정보를 코드·영상·로그·스크린샷에 넣지 않는다.

## 1. 작업 흐름 (한 회차)

작업 지시와 영상 → ① 물품 선택 → ② 위치 확인 → ③ 이동 → ④ 접근·집기·놓기 → ⑤ 결과 확인 → 결과 기록

| 단계 | 로봇이 하는 일 | 다음 단계로 넘길 것 |
|---|---|---|
| ① 물품 선택 | 영상+지시를 함께 보는 **VLM**으로 작업할 물품을 고른다 | 선택한 물품 또는 **보류 이유** |
| ② 위치 확인 | 카메라로 방향·거리를 구해 **로봇 기준 좌표**로 바꾼다 | 물품 위치와 **길이 단위** |
| ③ 이동 | 센서로 만든 **지도**로 작업 장소까지 이동. 장애물이면 안전 정지, 우회 가능하면 다른 길로 재개 | 도착 여부 |
| ④ 접근·집기·놓기 | 셋 중 **하나 이상은 VLA**에 맡긴다. 나머지는 기존 제어 가능 | 실행한 동작, 실제 물품 상태 |
| ⑤ 결과 확인 | **새 관측**으로 목표 위치에 놓였는지 확인, 목표와 실제 위치 차이 기록 | 성공·실패·미확인 + 영상·실행 기록 |

| 필수 · 물품 판단 | VLM으로 대상 선택, **정상·모호·부재** 시험 | 모호·부재면 **보류하고 후속 동작 차단** |
| 필수 · 위치·주행 | 3D 위치 + 로봇 기준 좌표, SLAM 지도에서 목표 주행 + 장애물 회피 | 물품 위치 오차와 지도 실측 차이를 각각 확인. **정지와 우회·재개를 구분** |

| 필수 · 연결·검증 | 물품 하나부터 전체 연결, 지표 계산·실패 분석·기록 재현 | 실패·미확인·수동 개입도 원본에 남김 |
| 선택 확장 | 조명·가림·장애물 배치·집기 접근법 중 한 조건을 바꿔 비교 | 기본 공정 재현 뒤에, 필수 대체 불가 |
| 평가 제외 | 여러 로봇의 군집·편대 | |

## 3. 미션 설계 규칙

**명세서 필수 항목**: 미션 한 문장, 문제/출처, 시작 상태, 작업 지시, 공정 순서 · VLA 담당 동작과 허용 범위, 정상/모호/부재 판정 · 성공/실패/미확인 조건, 측정 방법/허용 오차, 재시도/개입 기준, 버전/변경.

**올바른 미션 점검** (하나라도 아니면 범위를 줄이고 튜터 검토):
1. 한 문장에 물품·출발 위치·도착 구역이 모두 있는가
2. VLM 선택 → 3D 위치 → Nav 이동 → 조작 → 배치 확인이 **한 회차 안에서** 이어지는가
3. 정상·모호·부재 장면을 실제 물품으로 만들 수 있는가
4. 성공을 mm 같은 **측정값**으로 판정할 수 있는가
5. 물품 크기·무게, 팔 도달 범위, 카메라 측정 거리가 배정 장비 안인가
6. 물품 1개 전체 공정을 일정 안에 먼저 끝낼 수 있는가

**피할 미션**: 성공을 잴 수 없는 목표("깔끔하게 정리하기"), 팔이 안 닿거나 그리퍼보다 큰 물품, 여러 로봇이 필요한 작업, 기능 하나만 보여주는 시연.

**변경 이력**: 평가 결과를 본 뒤 과거 회차를 유리하게 바꾸지 않는다. 기준을 바꾸면 새 버전과 적용 회차를 기록하고 영향받는 시험을 다시 한다. 팀이 채울 값(위치·단위·허용 오차·모델 행동 범위·재시도 조건)이 남은 채로 평가용 시험을 시작하지 않는다.

## 4. 시험·기록 규칙

| 시험 | 목적 | 집계 |
|---|---|---|
| 연습 | 개발 중 조정 | 평가 지표에 안 넣음, 끝난 뒤 평가용으로 바꾸지 않음 |
| 평가용 단위 시험 | 물품 선택·행동 거부·장애물 회피·집기·지도 측정 등 한 기능 | 기능별 따로, 전체 공정 성공률에 안 넣음 |
| 평가용 전체 공정 | 선택부터 최종 확인까지 | **시작한 회차 전부** 분모 (중단·실패·미확인·개입 포함) |

- **실행 전**: 연습/평가, 단위/전체, 회차 ID·미션 버전·시작 상태·기대 결과. VLM 단위 시험은 정상·모호·부재 유형을 먼저 지정.
- **판단·행동**: VLM은 정상에서 선택, 모호·부재에서 보류·차단 확인. VLA는 **원출력·변환값·위치 기준·단위·허용 범위·명령 전송 여부**를 남김.
- **실행 중**: 실물/시뮬레이션/오프라인, 입력 출처(실시간 모델/기록 출력/시험용 입력) 구분. 자동 재관측·재시도와 사람 개입을 구분하고 시각·사유.
- **종료 후**: 판정, 측정값·단위, 영상·로그 위치.
- **위험 시**: 즉시 정지, 중단 단계·원인 기록. 수동 복구 후 초기 상태에서 다시 시작하면 **새 회차**.

### 지표 계산

- **VLM 유형별 정확도** = (평가용 VLM 단위 시험 중 최초 판단이 정답인 회차) ÷ (그 유형의 평가용 VLM 단위 시험 회차). 모호·부재에서 올바르게 보류+차단이면 정답. 재관측해도 같은 회차는 한 번.
- **전체 공정 자율 성공률** = (개입 없이 완료가 확인된 회차) ÷ (사전에 지정한 전체 공정 평가 회차). 보류·미확인·실패·수동 개입은 분모에 남고 분자에는 없음.
- 허용한 자동 재시도 안에서 성공하면 성공 1회 (파지 시도는 같은 회차 ID에 2건 기록). 허용 초과·개입은 자율 성공 아님.
- **사이클 타임**: 사전 정의한 시작~종료. **처리량**: 관측 시간당 완료 수.
- 예: 전체 공정 4회 중 자율 완료 2, 미확인 1, 수동 개입 완료 1 → 자율 성공률 2/4.

## 5. 항목별 수행 기준과 불인정 사례

| # | 항목 | 수행 기준 | 불인정 |
|---|---|---|---|
| ① | 맵 | 7개 후보 중 추첨한 같은 맵 | 추첨 뒤 자기 맵 사용, 통로 넓히기 |
| ② | 미션 설계 | 입고·검사·분류·이송·적재 중 상황, 대상·수량·출발·작업대·도착 | 팔/주행 영상 하나로 전체 완료 판정 |
| ③ | 3D 비전 | RGB-D·스테레오·표식 크기 자세 추정 등 | 2D 박스/ID만, **미리 적은 좌표를 검출 3D 위치라고 기록** |
| ④ | VLM·VLA | VLM: 정상 하나 선택, 모호(후보 2개 이상)·부재 보류+차단, 실시간/녹화 영상 모두 가능(그 회차에 추론). VLA: 현재 영상·지시의 **원출력 → 어댑터 변환 → 좌표계·단위·허용 범위 검사 → 유효 후보 실물 실행** | 저장 출력 재생만으로 VLM 시험(재현 근거로만) |
| ⑤ | Pick-and-Place | VLA 담당은 어댑터로 변환, 나머지는 기하 계산·기존 제어기 가능 | 사람이 그리퍼에 끼워 주기, 놓인 위치 손으로 고치기 |
| ⑥ | SLAM 지도 | 실물 주행으로 생성·저장, Nav 재사용, 실측과 지도값 비교(같은 단위) | 도면 이미지를 불러오기만 |
| ⑦ | Nav·장애물 | 우회 가능 통로에서 **정지 → 재계획 → 충돌 없는 우회 → 재개**. 우회 불가 안전 대기는 별도 기록 | 원격조종, 속도 명령 시간순 재생, 정지만 하고 우회 성공 기록 |
| ⑧ | 통합 | 관측값이 다음 단계 목표, 도착·파지·배치 확인 결과로 상태 전이 | 기능별 성공 영상 이어 붙이기 |
| ⑨ | 개입·안전 | 시작 후 사람의 재지시·대상 지정·위치 조정 = 개입(시각·사유, 자율 성공 제외). 로봇의 자동 재관측은 자율 | 수동 복구 숨김, **시뮬레이션 성공을 실물 성공으로 합산** |
| ⑩ | 지표·재시도 | 위 계산식 | 실패 회차를 분모에서 빼기, 결과 본 뒤 허용 오차 넓히기 |
| ⑪ | bag 재현 | 영상·지시·VLM/VLA 원출력·TF·실행 상태를 같은 회차로. 다른 팀원이 재생해 선택·보류, 변환·거부, 완료 판정을 **재계산**·대조 | 최종 성공 메시지만 재생. 기록된 3D 좌표 사용은 "3D 결과 재생", 검출기 재실행만 "3D 검출 재실행" |
| ⑫ | 공통 환경 변경 | 튜터에게 알리고, 팀 내부 변경은 버전·적용 회차 | 구두 답변을 공통 규칙으로 간주 |
