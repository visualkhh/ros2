# ml/vlm — 물품 선택 (영상 + 지시 → 대상 또는 보류)

> 상태: **개념**. 코드·데이터 없음. CPU만 쓴다.

## 맡는 일

입력: 카메라 영상(RGB, 필요하면 깊이) + 지시(예: "캔을 넣어", "전부 분리수거해")
출력(JSON):

```json
{"decision": "select | hold",
 "reason": "ambiguous | absent | low_confidence | ok",
 "target": {"category": "can", "label": "콜라 캔", "bbox": [x0, y0, x1, y1], "pixel": [u, v], "confidence": 0.91},
 "candidates": [{"category": "pet", "bbox": [...], "confidence": 0.88}]}
```

- 정상: 지시를 만족하는 물품 **하나** 선택 → `pixel`을 깊이·TF로 3D 위치(base_link, mm)로 바꿔 다음 단계로
- 모호(분류 불확실·같은 조건 후보 둘 이상)·부재: `hold` → 후속 동작 차단 (발제 필수)
- 미션 규칙 "후보가 여럿이면 접근·집기가 가능한 것부터": 후보 목록에 거리·가림·자세(누움/섬)를 붙여 **선택 규칙은 코드**가 정한다 (모델이 아니라 결정적 규칙 → 재현·검증 쉬움)

## 방식 (CPU 기준) — 2단 구조

| 단 | 무엇 | 왜 |
|---|---|---|
| 1. 검출·분류기 | 작은 검출기(예: YOLO 계열 nano급) 또는 영역 제안 + **MobileNet급 분류기**: 물품 상자·종류(can/pet/paper/unknown/other)·신뢰도 | CPU에서 수십 ms, 시뮬 진실값으로 라벨 자동 생성 → **CPU로 학습 가능**. 분류 신뢰도로 "불확실 → 보류"를 수치로 판정 |
| 2. 작은 VLM | SmolVLM2급(수억 파라미터, 이미 `vlm_node` sidecar가 쓴다), 필요하면 GGUF Q4로 llama.cpp | 지시의 뜻("빨간 거", "콜라") 연결, 분류기가 모르는 새 물품 설명, 결과 확인 질문 |

- 기본은 **1단만으로 판단**하고, 지시에 색·상표 같은 속성이 있거나 1단 신뢰도가 애매할 때만 2단을 부른다 (CPU 시간 절약).
- VLM 전체 미세조정은 CPU로 비현실적 → **프롬프트 + 소수 예시**로 쓰고, 해볼 만하면 LoRA를 작은 모델에 밤새 돌리는 정도까지만.

## 데이터

- 시뮬레이터 `srf_recycling_ws_snapshot`으로 생성: 시드 × 장면(normal/multi/ambiguous/absent) × 로봇 자세 × 팔 자세 × 사람·지게차 유무
  - 라벨: `truth.json`의 물품 종류·변형·위치 → 카메라로 투영한 **2D 상자**(스냅샷 도구에 추가 예정)
  - 지시 템플릿: "캔 넣어", "페트병만", "종이 치워", "전부 분리수거해", "빨간 캔" … × 기대 결정(select/hold, 정답 물품)
- 도메인 무작위화: 조명 세기·방향, 라벨 브랜드·색, 카메라 잡음·노출, 물품 자세
- **실물 사진**: 실제 캔·페트·종이를 실습 공간에서 수십~수백 장 (평가용은 학습에 쓰지 않는다)

## 학습 (CPU)

- 분류기: 사전학습 MobileNetV3-small/EfficientNet-lite에서 마지막 층들만 → 수천 장 기준 CPU 수 시간
- 검출기: nano급 사전학습 모델 미세조정, 이미지 크기 320~416 → CPU 하룻밤
- 산출물: ONNX(int8 양자화) → `artifacts/models/vlm/<버전>/`

## 추론

- 1단: C++ onnxruntime(CPU) — 엔진에 이미 있는 런타임. 또는 sidecar
- 2단: 기존 `vlm_node` → HTTP sidecar (SmolVLM2)
- 목표: 1단 < 100 ms, 2단 호출 시 수 초 이내

## 평가 (발제 지표 그대로)

- 평가용 VLM 단위 시험: 시작 전 유형(정상·모호·부재)을 정하고, **최초 판단**이 정답인 회차 / 그 유형 회차 수
- 실물·시뮬을 따로 집계. 기록: 회차 ID, 영상 출처, 지시, 원출력, 후속 동작 실행·차단 여부
