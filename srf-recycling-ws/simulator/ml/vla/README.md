# ml/vla — 팔 행동 (영상 + 지시 + 상태 → 접근·집기·놓기)

> 상태: **개념**. 코드·데이터 없음. CPU만 쓴다.

## 맡는 일

미션 원문은 VLA가 인식·분류·접근·집기·이동·놓기를 맡는다고 했지만, 발제 필수는 "접근·집기·놓기 중 **하나 이상**"이다. CPU 현실을 고려해 **단계적으로** 늘린다:

1. **접근**(그리퍼를 물품 위 프리그래스프 자세로) — 먼저
2. **집기**(내려가서 닫기)
3. **놓기**(바구니 위로 옮겨 열기)

인식·분류는 [`vlm/`](../vlm/README.md), 이동은 Nav가 맡는다 (발제 구조와 맞춤).

## 입·출력

- 입력: RGB(작게, 예 128×128~224×224) + (선택) 깊이 + 관절 상태(joint1~4, gripper) + 지시(종류 one-hot 또는 문장 임베딩) + VLM이 고른 대상의 이미지 좌표
- 출력: **행동 청크** — 앞으로 N스텝(예 8~16, 4 Hz)의 관절 목표(rad) + 그리퍼(m)
- 어댑터(엔진, 모델 밖): 좌표계·단위 확인 → 관절 한계·속도·작업 영역 상자·충돌 검사 → **범위 밖 후보는 명령 전송 없이 거부하고 기록** (발제 ④)

## 방식 (CPU 기준)

| 후보 | 크기 | CPU 학습 | CPU 추론 | 판단 |
|---|---|---|---|---|
| **작은 자체 정책** (CNN 인코더 + 지시 임베딩 → 행동 청크, ACT/BC 계열) | 수백만~2천만 | 수 시간 (수천 에피소드) | 수~수십 ms | **기본안** |
| SmolVLA (LeRobot) | 약 4.5억 | 매우 느림 (며칠) | 청크 단위 저주기면 가능 | 비교·확장용 |
| OpenVLA·π0 등 대형 | 수십억 | 불가 | 불가 | 제외 |

기본안 구조:

```
RGB ─▶ MobileNet/ResNet18(사전학습, 앞부분 고정) ─┐
깊이 ─▶ 작은 CNN (선택) ───────────────────────────┤
관절 상태 ─────────────────────────────────────────┼─▶ MLP/작은 Transformer ─▶ 행동 청크 (N × 5)
지시 (종류 one-hot / 문장 임베딩) ─────────────────┤
대상 좌표 (VLM) ───────────────────────────────────┘
```

- "Vision-Language-Action"의 조건(영상·지시 → 행동)을 만족하면서 CPU에서 학습·추론되는 크기
- 청크 + 시간 앙상블로 떨림을 줄인다 (기존 `vla_node`가 4 Hz 청크 실행을 이미 한다)

## 데이터 — 시뮬레이터 전문가 시연

- **스크립트 전문가**: 시뮬레이터는 물품 진실 위치를 알고, 팔 IK/MoveIt 스택이 있다 → 접근·집기·놓기 궤적을 자동 생성
- 기록: `srf bag record`로 영상·깊이·관절·지시·행동을 같은 회차로 (MCAP) → 변환 스크립트로 학습 형식(필요하면 LeRobot 형식)
- 무작위화: 물품 종류·자세(서기/눕기)·위치, 조명, 카메라 잡음, 사람이 지나가는 방해
- 실패 복구 데이터: 전문가 궤적에 잡음을 넣고 되돌아오는 시연 (DAgger식 반복은 선택)
- **실물 시연 소량**: 수동 조작(팔 패널·텔레옵)으로 수십 회 → 미세조정·평가

## 학습 (CPU)

- PyTorch CPU, 인코더 앞부분 고정 + 이미지 특징 **미리 계산해 캐시** → 학습은 MLP/작은 헤드만 → CPU로 충분
- 산출물: ONNX(int8) → `artifacts/models/vla/<버전>/`

## 추론

- **C++ onnxruntime(CPU) in-process**를 우선 검토 (엔진이 RL 주행에 이미 쓰는 방식, `engine/ml/onnx_policy.cpp`) → HTTP 왕복 없음
- 또는 기존 `vla_node` sidecar 인터페이스(HTTP) 유지 — 노드가 주기·안전·컨트롤러 전환을 소유하는 구조는 그대로

## 평가

- 시뮬: `recycling/truth`로 자동 채점 — 접근 오차(mm), 집기 성공, 놓기 후 바구니 안·낙하
- 실물: 발제 지표 (VLA 담당 동작의 실행 결과, 전체 배치 오차, 집기 실패·낙하 포함)
- 기록: 원출력, 변환값, 위치 기준, 단위, 허용 범위, 명령 전송 여부, 거부 사유
