# Isaac 개념 정리

sim 보정·학습에서 나오는 말을 하나씩. 절차(명령어)는 링크한 문서에 있고, 여기는 **"이게 뭐고 왜 하나"** 만.

## gain · 지연 · τ — 모터 반응을 숫자 3개로 (fit.json)

명령이 바뀐 순간(계단)부터 실제 바퀴 속도가 어떻게 따라오는지를 요약한 값. calibration이 real·sim 각각에서 재서 `fit.json`에 남긴다.

```text
속도
 목표 ─────────────┬─────────────────   ← 명령 (계단)
                   │        ______ ← gain × 목표 (끝까지 따라간 높이)
                   │      /
                   │    /   ← τ: 거기까지 올라가는 빠르기 (63%에 닿는 시간)
 ──────────────────┴──/
                   |←→| 지연: 명령 후 움직이기 시작할 때까지
```

| 값 | 뜻 | 1보다 작으면 / 크면 |
|---|---|---|
| **gain** | 실제 속도 ÷ 명령 속도 (정상 상태) | 덜 감 (예: 0.9 = 10% 느림) / 더 감 |
| **지연** [s] | 명령이 바뀐 뒤 바퀴가 반응하기 시작할 때까지 | 통신·처리·모터 지연 |
| **τ** [s] | 반응을 시작한 뒤 목표의 63%까지 오는 시간 | 클수록 굼뜸 |

- 좌우 바퀴의 gain이 다르면 직진 명령에도 휘어진다 → RL이 보정하는 대상 중 하나.
- `--fit real,sim`: real − sim 차이를 학습 env의 바퀴 지연·gain 랜덤 범위의 **중심**으로 써서 sim을 실기기 쪽으로 옮긴다
