# TurtleBot3 waffle pi (ROBOTIS)

`urdf/turtlebot3_waffle_pi.urdf`와 `meshes/`는 ROBOTIS 저장소에서 **수정 없이** 받은 파일이다.

- 출처: https://github.com/ROBOTIS-GIT/turtlebot3/tree/main/turtlebot3_description (urdf/, meshes/)
- 받은 시점의 해당 폴더 최신 커밋: `b0811c774bd6257809d011ddb55d39362eca4256` (2026-11-10)
- 라이선스: Apache-2.0 (저장소 기준)
- 파일: `meshes/bases/waffle_pi_base.stl`, `meshes/wheels/{left,right}_tire.stl`, `meshes/sensors/lds.stl`

URDF의 `package://turtlebot3_description/<경로>`는 이 폴더(`description/`)의 `<경로>`로 읽는다.
